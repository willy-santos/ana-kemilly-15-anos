# Ana's Stellar Journey

Crie um site de convite digital para uma festa de 15 anos.

Informações do evento

Aniversariante: Ana Kemilly

Data: Domingo, 15 de novembro de 2026

Horário: A partir das 10:00

Local: Passagem Jardim Brasil, 54 - Levilândia, Ananindeua - PA, 66650-204

Tema visual

O tema da festa é Universo Observável, inspirado em:

Astronautas

Lua

Planetas

Estrelas

Galáxias

Constelações

Nebulosas

Sistema solar

Espaço sideral

Porém, o design não deve ser excessivamente sério, científico ou realista. Quero uma estética bonita, jovem, divertida e delicada, adequada para uma festa de 15 anos.

Misture elementos do espaço com uma identidade visual de aniversário adolescente. O resultado deve parecer um convite moderno e especial, e não uma página de astronomia.

Direção visual

Use uma atmosfera espacial com:

Fundo escuro inspirado no espaço profundo;

Gradientes suaves;

Estrelas pequenas espalhadas pelo fundo;

Nebulosas e brilhos discretos;

Planetas estilizados;

Lua;

Pequenos astronautas ou elementos espaciais de maneira divertida;

Efeitos de brilho e partículas;

Animações suaves;

Elementos flutuando lentamente para dar sensação de profundidade.

Evite exagerar nos elementos para não deixar a página poluída.

A paleta pode ser baseada em tons de azul-escuro, roxo, lilás, rosa suave, branco e pequenos pontos de luz.

A tipografia deve ser elegante e moderna, mas continuar fácil de ler.

Estrutura do site

Crie uma página inicial impactante com:

"15 anos de Ana Kemilly"

e uma frase relacionada ao universo, por exemplo:

"Uma nova órbita começa..."

Abaixo, mostrar claramente:

Domingo, 15 de Novembro de 2026
A partir das 10:00

Passagem Jardim Brasil, 54
Levilândia, Ananindeua - PA

Adicionar uma contagem regressiva para o evento, mostrando dias, horas, minutos e segundos.

Navegação

O convite deve possuir uma navegação moderna, podendo ser uma barra superior ou menu elegante.

Criar as seguintes abas/seções:

1. Início

Apresentação principal da aniversariante e do evento.

Deve ser a parte mais visual do site.

2. Mensagem da aniversariante

Criar uma seção reservada para uma mensagem pessoal da Ana Kemilly.

Por enquanto, deixar um texto provisório claramente identificado ou um espaço preparado para substituição posteriormente.

Não inventar uma mensagem definitiva em nome da aniversariante.

A seção deve permitir futuramente substituir facilmente o texto.

3. Recadinhos

Criar uma área onde os convidados possam deixar mensagens para a aniversariante.

Essa área deve ser opcional e ter uma interface bonita.

Criar:

Campo para nome;

Campo para escrever o recado;

Botão "Enviar recadinho";

Área onde os recados enviados aparecerão.

Preparar a estrutura para armazenamento dos recados.

Se for necessário utilizar um backend, deixar a arquitetura preparada para integração com banco de dados posteriormente.

Os recados devem ter uma aparência semelhante a pequenas mensagens/cartões flutuando no espaço.

4. Presentes

Criar uma seção chamada "Opções de presente".

O conteúdo dessa seção ainda será definido posteriormente.

Por enquanto, criar uma estrutura bonita com espaço reservado para adicionar futuramente:

Nome do presente;

Imagem;

Descrição;

Eventual link;

Status/opção de escolha, caso necessário.

Não inventar opções de presentes.

Deixar essa seção facilmente editável.

5. Localização

Adicionar uma seção com o endereço completo:

Passagem Jardim Brasil, 54 - Levilândia, Ananindeua - PA, 66650-204

Adicionar um botão como:

"Ver localização"

que futuramente poderá abrir a localização no Google Maps.

Também pode incluir um mapa incorporado se isso puder ser feito de maneira simples e responsiva.

Experiência do usuário

O site deve ser:

Responsivo para celular, tablet e computador;

Priorizar a experiência em celular, pois provavelmente será acessado pelos convidados através do WhatsApp;

Rápido;

Visualmente bonito;

Fácil de navegar;

Com animações suaves;

Sem excesso de elementos;

Com boa acessibilidade e contraste.

Criar transições suaves entre as seções.

Adicionar pequenos efeitos de estrelas, partículas ou objetos espaciais se movendo lentamente pelo fundo.

Ao entrar no site, pode haver uma pequena animação inicial, como uma estrela cadente ou um astronauta aparecendo, mas ela deve ser rápida e não atrapalhar o acesso ao convite.

Detalhes importantes

Não transformar o site em uma página genérica de casamento.

É especificamente um convite digital de 15 anos, com uma estética jovem, divertida, elegante e espacial.

O tema "Universo Observável" deve estar presente em todo o design, mas de forma delicada.

Evite:

Design infantil demais;

Design excessivamente formal;

Excesso de elementos;

Visual científico;

Textos muito longos;

Animações exageradas;

Cores muito saturadas.

Quero que a primeira impressão seja de:

"Uau, esse convite é muito bonito e diferente."

Preparação para futuras alterações

Estruture o código de maneira organizada para que seja fácil posteriormente alterar:

Mensagem da aniversariante;

Lista de presentes;

Imagens;

Textos;

Recadinhos;

Informações do evento.

Não coloque informações fictícias onde eu ainda não forneci conteúdo.

Use componentes reutilizáveis e mantenha os dados do convite separados da estrutura visual sempre que possível.

Crie o projeto completo com aparência profissional, pronto para ser visualizado e posteriormente publicado.
